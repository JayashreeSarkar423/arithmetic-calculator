# Advanced Arithmetic Calculator

A Python-based command-line calculator that performs a variety of arithmetic operations, including basic calculations and advanced mathematical functions. This project is designed for beginners learning Python as well as anyone needing a lightweight calculator application.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Integer Division
- 🔢 Float Division
- 🧮 Exponential (Power) Calculation
- 📊 Modulus (Remainder) Calculation
- ⚡ Fast and lightweight command-line interface
- 🛡️ Basic error handling for invalid inputs

## Supported Operations

| Operation | Symbol | Example | Result |
|------------|---------|---------|---------|
| Addition | `+` | `10 + 5` | `15` |
| Subtraction | `-` | `10 - 5` | `5` |
| Multiplication | `*` | `10 * 5` | `50` |
| Integer Division | `//` | `10 // 3` | `3` |
| Float Division | `/` | `10 / 3` | `3.3333` |
| Exponential | `**` | `2 ** 3` | `8` |
| Modulus | `%` | `10 % 3` | `1` |

## Requirements

- Python 3.x

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/advanced-arithmetic-calculator.git
```

2. Navigate to the project directory:

```bash
cd advanced-arithmetic-calculator
```

## Usage

Run the calculator:

```bash
python calculator.py
```

### Example

```text
===== Arithmetic Calculator =====

Enter first number: 10
Enter operation (+, -, *, //, /, **, %): **
Enter second number: 2

Result: 100
```
